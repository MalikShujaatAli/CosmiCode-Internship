# CosmiCode Machine Learning Internship — 2025

Everything I built during a six-week structured machine learning internship at **CosmiCode Technologies**
(Lahore, July–September 2025). One folder per week, ending in a capstone.

It is coursework, kept public because the progression is the point: Python fundamentals in week 1,
a trained and evaluated classifier by week 6.

---

## The six weeks

### Week 1 — Python foundations
CRUD over lists, dictionaries, tuples and sets; recursion (factorial, Fibonacci); string algorithms
(palindrome check, vowel counting, reversal); prime checking; a grade calculator.
→ 12 notebooks

### Week 2 — NumPy and pandas
Array operations (sum, mean, max, reshape), loading and conditioning DataFrames, handling missing data,
descriptive statistics. Worked on an age-prediction dataset.
→ 6 notebooks

### Week 3 — Visualisation
Line, bar, scatter, histogram and pie charts; correlation heatmaps and pairplots in Matplotlib and
Seaborn, applied to the Titanic dataset.
→ 6 notebooks

### Week 4 — Structured exploratory data analysis
A full EDA pass on Titanic: data loading, missing-value strategy, then univariate, bivariate and
multivariate analysis with a correlation heatmap — with the figures saved alongside the notebooks.
→ 6 notebooks + 8 saved plots

### Week 5 — scikit-learn
Linear regression, logistic regression, decision trees, random forests, and model evaluation with
plotted metrics.
→ 5 notebooks

### Week 6 — Capstone: spam classification
UCI **Spambase** dataset. IQR outlier treatment on `capital_run_length_average`, feature scaling with
`StandardScaler`, then **logistic regression, decision tree and random forest compared like for like**
rather than reporting only the best one.
→ notebook, dataset and written project report

---

## Running the notebooks

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

Datasets are committed alongside the notebooks (`Age Prediction.csv`, `Titanic-Dataset.csv`,
`spambase.csv`), so each one runs as-is.
